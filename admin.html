    Página

    Barra de filtros fixa no topo

    Clique num item do inventário para colocá-lo no primeiro espaço livre, ou arraste-o direto para a posição desejada. Arraste um card para reposicionar e use as alças das bordas (esquerda, direita, base e canto) para esticar — cada gráfico tem um tamanho mínimo de legibilidade, mas nenhum máximo.     Documentos

    Abrir página ↗

    Esta lista é o que aparece na página Repositório. Os arquivos ficam na pasta repository/ do GitHub (abrir pasta no GitHub ↗): envie-os aqui mesmo ou por lá e cadastre-os nesta lista. Mudanças na lista valem na hora; um arquivo novo leva cerca de 20 segundos para ficar disponível para download.

    Novo documento

    Origem
    1. até 3 MB Envie aqui. Fica pronto em um passo.
    2. 3 a 25 MB Suba pela pasta no GitHub e depois cadastre aqui, em "Já está no GitHub".
    3. 25 a 100 MB Peça ao Thiago: só sobe pelo terminal.
    4. mais de 100 MB Não cabe no GitHub. Divida o arquivo ou hospede na nuvem e cadastre só o link.
